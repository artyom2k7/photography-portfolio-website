# Photography Portfolio Website

> **Note:** This project is designed as a desktop-only layout (`Desktop-only`) to practice and master complex multi-column CSS Grid layouts, explicit coordinate mapping, and hover-driven visual effects.

A clean, modern, and high-contrast multi-section landing page designed as a personal portfolio for a professional photographer. Features a fluid graphical gallery and complex CSS layouts.

## Technologies Used
- **HTML5**: Semantic elements, structured layout wrappers (`<header>`, `<section>`, `<form>`), textareas, and interactive buttons.
- **CSS3**: Multi-column CSS Grid layouts (`grid-template-columns`, `grid-template-rows`), advanced positioning modules, explicit coordinate mapping via `grid-template-areas`, smooth transition effects, color transparency masking (`rgba`), and absolute styling.

## Key Features
- **Interactive Tiled Gallery**: Built using a robust 3-column CSS Grid. Implements multi-column spanning layouts (`grid-column: span 2`) and smooth transitions to toggle colored image masks on hover.
- **Advanced Layout Architecture**: Features an immersive header hero banner with absolute overlay components and a contact section utilizing complex multi-row grid template mapping.
- **Clean Structure**: Follows industrial best practices regarding document formatting and file path declarations.
